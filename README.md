# แบดมินตันกบินทร์บุรี-สวนน้อมเกล้า

เว็บแอพสำหรับแอดมินก๊วน: เช็คอินคนที่มาเล่น จัดคู่ลงสนามอัตโนมัติ และคิดเงินค่าสนาม ค่าลูก ค่าน้ำ พร้อม PromptPay QR ตามยอดของแต่ละคน

## กติกาคิดเงิน (แก้ได้ในแท็บ "ตั้งค่า")

| รายการ | สมาชิกรายเดือน | คนจ่ายรายวัน |
| --- | --- | --- |
| ค่าสนาม | 150 บาท/เดือน ไม่คิดรายวัน | 40 บาท/ครั้ง |

ระบบดูจากรายการจ่ายรายเดือนของเดือนนั้นๆ (แท็บคิดเงิน > รายเดือน) ใครจ่ายเดือนนั้นแล้วจะไม่ถูกคิดค่าสนามรายวันอัตโนมัติ แอดมินแก้สถานะย้อนหลังได้
| ค่าลูก | ลูกแรกของวัน 30 บาท ลูกต่อไป 25 บาท ต่อคน | เหมือนกัน |
| ค่าน้ำ | ตามจริง | ตามจริง |

ยอดที่ยังไม่จ่ายจะยกไปรวมกับครั้งถัดไป และกด "ได้รับเงินแล้ว" ครั้งเดียวปิดยอดค้างทั้งหมด

## ระดับมือ

New < BG < N < S < P

## การจัดคู่

- คนที่เล่นน้อยที่สุดวันนี้ได้ลงก่อน ถ้าเท่ากัน คนที่รอนานกว่าได้ก่อน
- คนต้นคิวได้ลงเสมอ อีก 3 คนเลือกจากคนต้นคิวให้ฝีมือใกล้กัน
- แบ่งทีมให้ระดับฝีมือรวมสองฝั่งใกล้กันที่สุด และเลี่ยงคู่ซ้ำ

## ออนไลน์ด้วย Supabase

ถ้าตั้งค่า `NEXT_PUBLIC_SUPABASE_URL` และ `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (ดู `.env.example`) แอพจะเก็บข้อมูลบน Supabase และอัปเดตทุกเครื่องแบบเรียลไทม์ ถ้าไม่ตั้ง จะเก็บในเครื่องแทน

- **ผู้เล่นทั่วไป** เปิดลิงก์แล้วดูสนาม คิว และยอดของตัวเองพร้อม QR ได้ แก้ไขอะไรไม่ได้
- **แอดมิน** เข้าสู่ระบบด้วยลิงก์ทางอีเมล อีเมลที่เป็นแอดมินอยู่ในตาราง `admins` (ตัวพิมพ์เล็ก) เพิ่มได้ใน Supabase > Table Editor
- สิทธิ์คุมด้วย RLS: ทุกคนอ่านได้ เฉพาะแอดมินเขียนได้ เบอร์โทรเห็นเฉพาะแอดมิน

## พัฒนา

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # เทสต์สูตรคิดเงิน การจัดคู่ และ PromptPay QR
npm run lint
npm run build
```

โค้ดหลักอยู่ใน `src/lib` (`billing.ts`, `matchmaking.ts`, `promptpay.ts`) หน้าจออยู่ใน `src/components`

## ทดลองใช้ (โหมดทดลอง)

เปิดเว็บแล้วเติม `?demo` ท้ายลิงก์ เช่น `https://<เว็บ>.vercel.app/?demo` จะได้ข้อมูลตัวอย่างผู้เล่น 12 คน
และแถบด้านบนสำหรับสลับดูแบบ **ผู้เล่น** หรือ **แอดมิน** ข้อมูลในโหมดนี้อยู่ในเครื่องที่เปิดเท่านั้น ไม่แตะข้อมูลจริงใน Supabase

## ภาษา

ปุ่ม ไทย / EN / 中文 อยู่มุมขวาบน คำแปลอยู่ที่ `src/lib/i18n/en.ts` และ `zh.ts` โดยใช้ข้อความภาษาไทยเป็นคีย์
เทสต์ `i18n.test.ts` จะแจ้งถ้ามีข้อความใหม่ที่ยังไม่ได้แปล
